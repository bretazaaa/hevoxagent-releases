# Hevox Support

Need help with Hevox Agent?

Before requesting support, please make sure that:

* You are running the latest version.
* Your system meets the requirements.
* Hevox Agent can communicate with your Hevox Panel.
* You have checked the available documentation.

## Bug Reports

If you believe you have found a bug, open a GitHub Issue and provide:

* Hevox Agent version
* Operating system
* Installation method
* Steps to reproduce the problem
* Relevant logs

## Security Issues

Security vulnerabilities must not be reported through public GitHub Issues.

Please refer to [SECURITY.md](SECURITY.md).
