# hevoxagent releases

This repository contains **only built binaries** (`.deb` packages)
published automatically by CI from the private `hevoxagent` source
repository. No source code lives here.

## Install

```sh
curl -sSL https://raw.githubusercontent.com/bretazaaa/hevoxagent-releases/main/install.sh | sudo bash
```

See [Releases](../../releases) for individual `.deb` downloads.
