# Security Policy

Security is an important part of Hevox Agent.

## Reporting a Vulnerability

Please **do not publicly disclose security vulnerabilities through GitHub Issues**.

If you discover a vulnerability affecting Hevox Agent, please contact the Hevox team privately.

When reporting an issue, include:

* A description of the vulnerability
* Steps to reproduce it
* The affected Hevox Agent version
* Your operating system
* Any relevant logs or screenshots

Please allow reasonable time for the issue to be investigated and fixed before publicly disclosing it.

## Supported Versions

Security fixes are provided for the latest available version of Hevox Agent.

We strongly recommend keeping your Agent installation up to date.
